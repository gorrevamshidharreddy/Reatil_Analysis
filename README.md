Retail Sales Analysis Dashboard

This project demonstrates an end-to-end retail sales analytics solution using MySQL, Python, and Power BI. 
A synthetic dataset of 8,000+ sales transactions was generated using Python and stored in a relational MySQL database.  
An interactive Power BI dashboard was built to analyze revenue, profit, store performance, and customer trends.

Tools & Technologies Used
- MySQL
- SQL
- Python (Data Generation)
- Power BI
- DAX
- Data Modeling

Database Schema
The database consists of the following tables:

- customers
- products
- sales
- stores
- categories

Relationships were created using primary and foreign keys to build a proper star schema model.

Key Metrics Created
- Total Revenue
- Total Profit
- Total Quantity Sold
- Store-wise Revenue
- Monthly Revenue Trend
- Category-wise Contribution
- Top Customers by Spending

Dashboard Insights
- Identified top-performing stores based on revenue
- Analyzed monthly revenue patterns
- Determined high-value customers
- Evaluated category-level profit contribution
